# G9-LATAM-TEAM-32
Solución inteligente para seguimiento y análisis del comportamiento y estado financiero de un usuario a partir de sus datos financieros tales como: información relacionada con gastos y hábitos financieros, descripción de transacciones, montos, categorías de gastos, ingresos mensuales, frecuencia de ahorro, nivel de endeudamiento, entre otros.
